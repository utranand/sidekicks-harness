# bmad

The BMAD delivery pipeline: PRD, architecture, epic tech context, stories, dev, code review.

The BMAD family is the spec-driven path from a plan to merged code: PRD and epics, per-epic technical context, drafted stories, implementation, and review. Members share `sprint-status.yaml` as real state, so they are coupled by design rather than merely topical.
